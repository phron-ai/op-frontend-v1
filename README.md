# Project Title

OpenPhron

## Description

OpenPhron Marketplace provides a platform for users to explore various AI oracles and create smart contracts based on their ideas. The application consists of an AI Library for browsing oracles and a Workflow section for contract creation.

## Features

- **OracleList**: All oracles generated in this project will appear in the browser and create oracles.
- **Oracle subscription**: Input contract address and subscribe to a contract in oracle.
- **Smart Contract Creation**: Input ideas and create contracts seamlessly.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ainigmai0/op-frontend-v1.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up variables in .env file:

   -**REACT_APP_SERVER_URL**: http://your-Ip-Address:9001/api. (http://localhost:9001/api).

   -**REACT_APP_DEPLOY_URL**: http://your-Ip-Address:9002/contract. (http://localhost:9002/contract).

   -**REACT_APP_RECIPIENT**: Recipient wallet address that receives the tokens.

   -**REACT_APP_AMOUNT**: Amount of tokens transferred at once.

   -**REACT_APP_WALLET_CONNECT_PROJECT_ID**: project id for connect wallet.

   -**REACT_APP_WALLET_CONNECT_PROJECT_NAME**: project name for connect wallet.

   -**REACT_APP_PROMPT_ROLE**: prompt role.

   -**REACT_APP_PROMPT_ONE**: prompts.

   -**REACT_APP_PROMPT_TWO**: prompts.

   -**REACT_APP_PROMPT_THREE**: prompts.

   -**REACT_APP_PROMPT_FOUR**: prompts.

   -**REACT_APP_PROMPT_FIVE**: prompts.

   -**REACT_APP_PROMPT_SIX**: prompts.

4. Run the application:

   Start the Client

   ```bash
   npm start
   ```
